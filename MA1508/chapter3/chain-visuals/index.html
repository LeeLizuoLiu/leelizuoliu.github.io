Start with one composition

If y = f(g(x)), then dy/dx = f′(g(x))g′(x). Each factor measures one local change. A neural network repeats this idea: multiply derivatives along a path; add contributions when paths meet.

Our example has one input x, two hidden neurons with tanh activations, and one linear output ŷ (“y hat”). The target t is the answer we want. A weight scales a signal; a bias shifts it.

zᵢ = wᵢx + bᵢ   →   aᵢ = tanh(zᵢ),   i = 1, 2
ŷ = v₁a₁ + v₂a₂ + c   →   L = ½(ŷ − t)²

We use tanh because it is smooth: d(tanh z)/dz = 1 − tanh²z. The loss L measures the prediction error for this one example. All numbers below are recomputed when you move a control.

What does each control do?

x is the input and t is the target; both are fixed during a training step. w₁ and w₂ connect x to the hidden neurons, while b₁ and b₂ shift their inputs. v₁ and v₂ connect the activations to the output, and c is the output bias. Training adjusts the seven weights and biases.

Read one hidden path in detail

To differentiate with respect to wᵢ, follow the path wᵢ → zᵢ → aᵢ → ŷ → L. Hold the other parameters, x and t fixed. The symbol ∂ means “differentiate with respect to this one quantity”.

Predict before moving: set x = 0. Why does ∂L/∂wᵢ become zero, while ∂L/∂bᵢ can remain nonzero?

Explain the zero-input case

The local derivative ∂zᵢ/∂wᵢ is x, so it vanishes at x = 0. But ∂zᵢ/∂bᵢ = 1. The two gradients share every other factor, so the bias can still change the prediction even when the input weight cannot.

Use the gradients: one training step

Gradient descent subtracts a small multiple of each gradient: parameter_new = parameter_old − η × gradient. η (“eta”) is the learning rate. All seven updates use the same forward pass and happen together.

Backpropagation computes the gradients. Gradient descent uses them to update parameters. A large learning rate can increase the loss; the reported loss change tells you whether this step helped. This demonstration fits one example, not a dataset.

Why backpropagation is the chain rule

  1. Save the forward values. Compute z₁, z₂, a₁, a₂, ŷ and L. Their values determine the local derivatives.
  2. Begin at the loss. ∂L/∂ŷ = ŷ − t. This is the signal passed to both hidden paths.
  3. Multiply as you move backwards. ∂L/∂aᵢ = (ŷ − t)vᵢ, then ∂L/∂zᵢ = (ŷ − t)vᵢ(1 − aᵢ²). Reuse this last quantity for wᵢ and bᵢ.
  4. Add at a shared input. x influences both neurons, so ∂L/∂x = (∂L/∂z₁)w₁ + (∂L/∂z₂)w₂. Each parameter wᵢ belongs to one path; x belongs to two.
Why tanh can make a gradient small

For large |zᵢ|, tanh(zᵢ) is close to −1 or 1. Then 1 − aᵢ² is close to zero: a large change at zᵢ produces only a small change at aᵢ. This small local derivative reduces the gradient along that path. Set x = 1 and increase |wᵢ| to see this saturation.

Is the input gradient a training update?

Not in this example. We calculate ∂L/∂x to show how contributions from two paths add. The input and target are data; the training button updates only the weights and biases.

Where does the tanh derivative come from?

Write tanh z = (eᶻ − e⁻ᶻ)/(eᶻ + e⁻ᶻ). The quotient rule gives [(eᶻ + e⁻ᶻ)² − (eᶻ − e⁻ᶻ)²]/(eᶻ + e⁻ᶻ)² = 1 − tanh²z. Thus the neural-network example uses the exponential, quotient, and chain rules you already know.
