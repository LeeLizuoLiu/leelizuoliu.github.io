MA1508 Chapter 3.1 — Derivatives of Polynomials and Exponential Functions

The constant, power, constant-multiple, sum, difference and exponential rules, all proved from the limit definition.

1. Motivation, notation, and the definition we build everything on

Every function here is built from a constant, a power \(x^{n}\), and an exponential \(e^{x}\). For example

\[ f(x) = 4x^{5} - 2x^{3} + 7x - e^{x} + 3 \]

is a constant (\(3\)), the three power terms \(x^{5}, x^{3}, x^{1}\), and one exponential \(e^{x}\).

1.1 The definition of the derivative

Let \(f\) be defined on an open interval containing \(x\). Its derivative at \(x\) is the number

\[ f'(x) \;=\; \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}, \]

if the limit exists; then \(f\) is differentiable at \(x\) and the quotient is the difference quotient, the secant slope through \(\bigl(x, f(x)\bigr)\) and \(\bigl(x+h, f(x+h)\bigr)\); the tangent slope at \(x\) is \(f'(x)\).

1.2 Notation

All denote the derivative of \(f\):

\[ f'(x) \;=\; y' \;=\; \frac{dy}{dx} \;=\; \frac{df}{dx}(x) \;=\; \frac{d}{dx}\,f(x). \]

The symbol \(\dfrac{d}{dx}\) means "differentiate with respect to \(x\)": \(\dfrac{d}{dx}\bigl[x^{3}\bigr] = 3x^{2}\); with \(y=x^{3}\), \(\dfrac{dy}{dx} = 3x^{2}\). The operator is linear (§4).

1.3 Higher derivatives

Differentiating \(f'\) again gives the second derivative, and so on:

\[ f''(x) = \frac{d^{2}y}{dx^{2}}, \qquad f'''(x) = \frac{d^{3}y}{dx^{3}}, \qquad f^{(4)}(x) = \frac{d^{4}y}{dx^{4}}, \qquad \dots, \qquad f^{(n)}(x) = \frac{d^{n}y}{dx^{n}}. \]

For \(f(x) = x^{3}\),

\(f'(x) = 3x^{2}\) (power rule, \(n=3\)), \(f''(x) = \dfrac{d}{dx}\bigl[3x^{2}\bigr] = 3\cdot 2x = 6x\), \(f'''(x) = 6\), and \(f^{(4)}(x) = 0\) because \(6\) is a constant.

1.4 Which functions are covered here

Polynomials

A polynomial is a finite sum \(c_nx^{n} + \cdots + c_1x + c_0\), \(n\) a non-negative integer; its derivative is again a polynomial.

Exponentials

An exponential function is \(f(x) = a^{x}\) with base \(a > 0\). The natural exponential is \(f(x) = e^{x}\), with \(e = 2.718281828\ldots\) and \((e^{x})' = e^{x}\); §6 proves it.

2. The constant rule: \(\dfrac{d}{dx}(c) = 0\)

Let \(f(x) = c\) for all \(x\); its graph is horizontal, so the slope is \(0\).

\(\dfrac{d}{dx}(c) = 0\)
Proof (difference quotient)

Fix \(x \in \mathbb{R}\). Since \(f(x+h) = c\) and \(f(x) = c\),

\[ \frac{f(x+h) - f(x)}{h} = \frac{c - c}{h} = \frac{0}{h} = 0 \qquad \text{for every } h \neq 0. \]

The quotient is the constant \(0\) in \(h\), so its limit is \(0\):

\[ f'(x) = \lim_{h \to 0} \frac{f(x+h)-f(x)}{h} = \lim_{h\to 0} 0 = 0. \]

Limit law: limit of a constant; the cancellation \(0/h = 0\) holds for every \(h \neq 0\). Why it matters: a constant contributes nothing, so the "\(+3\)" in \(f(x) = 4x^{5}-2x^{3}+7x-e^{x}+3\) drops out. (Constants are the only functions with derivative identically \(0\) on an interval, but that needs the Mean Value Theorem, later.)

2.1 A closely related fact we need later

The constant rule is the case \(n = 0\) of \(n x^{n-1}\), valid for \(x \neq 0\) where \(x^{0} = 1\); the general rule follows from \(\dfrac{d}{dx}(c) = c\cdot\dfrac{d}{dx}(1) = 0\), since \(\dfrac{d}{dx}(1) = 0\cdot x^{-1} = 0\). §3 assumes \(n \ge 1\).

Example 1

A piecewise constant is differentiated only on the interior of its pieces.

3. The power rule for positive integers: \(\dfrac{d}{dx}\bigl[x^{n}\bigr] = nx^{n-1}\)

Statement. Let \(n\) be a positive integer and \(f(x) = x^{n}\). Then \(f\) is differentiable at every real \(x\) and

\(\dfrac{d}{dx}\bigl[x^{n}\bigr] = n\,x^{\,n-1}\)

with \(x^{0} = 1\) when \(n = 1\), so \(\dfrac{d}{dx}(x) = 1\). Positivity of \(n\) makes the binomial expansion finite; §5 removes this restriction.

3.1 The binomial theorem

Expanding \((x+h)^{n}\) gives \(n+1\) terms. Choosing \(h\) from \(k\) factors contributes \(\binom{n}{k}x^{n-k}h^{k}\), so

\[ (x+h)^{n} = \sum_{k=0}^{n} \binom{n}{k} x^{\,n-k} h^{k} \;=\; x^{n} + n\,x^{\,n-1}h + \binom{n}{2}x^{\,n-2}h^{2} + \cdots + n\,x\,h^{\,n-1} + h^{n}, \]

where \(\binom{n}{k} = \dfrac{n!}{k!\,(n-k)!}\), so \(\binom{n}{1} = n\). After dividing by \(h\), one term is left without an \(h\): \(nx^{n-1}\).

Proof (limit definition + binomial theorem)

Step 1 (form the difference quotient). Fix \(x\), \(h \neq 0\). By definition

\[ \frac{f(x+h)-f(x)}{h} = \frac{(x+h)^{n} - x^{n}}{h}. \]

Step 2 (expand the numerator). Substituting the expansion,

\[ (x+h)^{n} - x^{n} = \Bigl[ x^{n} + n x^{n-1}h + \binom{n}{2}x^{n-2}h^{2} + \cdots + n x h^{n-1} + h^{n} \Bigr] - x^{n}. \]

The \(x^{n}\) terms cancel:

\[ (x+h)^{n} - x^{n} = n x^{n-1}h + \binom{n}{2}x^{n-2}h^{2} + \cdots + n x h^{n-1} + h^{n}. \]

Step 3 (factor out \(h\)). Every remaining term contains an \(h\), so

\[ (x+h)^{n} - x^{n} = h\Bigl[\, n x^{n-1} + \binom{n}{2}x^{n-2}h + \cdots + n x h^{n-2} + h^{n-1} \Bigr]. \]

Step 4 (divide by \(h\)). Since \(h \neq 0\), the factor cancels, replacing \(\frac{0}{0}\) by a polynomial in \(h\):

\[ \frac{(x+h)^{n}-x^{n}}{h} = n x^{n-1} + \binom{n}{2}x^{n-2}h + \cdots + n x h^{n-2} + h^{n-1}. \]

Step 5 (let \(h\to 0\)). After the first term each term is (constant) \(\times\, h^{k}\) with \(k \ge 1\), and \(\lim_{h\to0}h^{k} = 0\); by the sum and constant-multiple laws every later term tends to \(0\). Hence

\[ \lim_{h\to0}\frac{(x+h)^{n}-x^{n}}{h} = n x^{n-1} + 0 + \cdots + 0 = n x^{n-1}. \]

Conclusion. \(f'(x) = n x^{n-1}\) at every real \(x\). (For \(n=1\): \((x+h)^{1} = x + h\), giving difference quotient \(h/h = 1 \to 1 = 1\cdot x^{0}\).)

3.2 The expansion made concrete for small \(n\)

For \(n = 2\), \((x+h)^{2} - x^{2} = 2xh + h^{2} = h(2x+h)\), so the quotient is \(2x + h \to 2x\). For \(n = 3\), \((x+h)^{3} - x^{3} = 3x^{2}h + 3xh^{2} + h^{3} = h\bigl(3x^{2} + 3xh + h^{2}\bigr)\), and the quotient is \(3x^{2} + 3xh + h^{2} \to 3x^{2}\).

Remark on a detail

The proof used \(\lim_{h\to0}h^{k}=0\) for \(k \ge 1\), which follows from the product law applied to \(h\cdot h\cdots h\), using \(\lim_{h\to0}h = 0\). No continuity of \(x^{n}\) is assumed.

3.3 Tangent lines and the derivative of \(x\)

\(\dfrac{d}{dx}(x) = 1\cdot x^{0} = 1\), so the tangent to \(y=x\) is the line itself. Likewise \(\dfrac{d}{dx}(x^{2}) = 2x\) vanishes only at \(x=0\), the vertex of \(y=x^{2}\) (compare the horizontal-tangent method in Example 7).

4. Sum, difference and constant-multiple rules

4.1 A continuity fact we need, and its proof

If \(f\) is differentiable at \(x\), then \(\lim_{h\to0}f(x+h) = f(x)\).

Proof

For \(h \neq 0\), by simple algebra,

\[ f(x+h) = f(x) + \frac{f(x+h)-f(x)}{h}\cdot h. \]

(Expand the right-hand side: the \(h\)'s cancel and \(f(x) - f(x) = 0\).) As \(h \to 0\), the quotient tends to \(f'(x)\) and \(h \to 0\). By the product law for limits,

\[ \lim_{h\to0} \frac{f(x+h)-f(x)}{h}\cdot h = f'(x)\cdot 0 = 0. \]

By the sum law for limits,

\[ \lim_{h\to0} f(x+h) = f(x) + 0 = f(x). \]

So differentiability forces \(\lim_{h\to0}f(x+h)=f(x)\): differentiable functions are continuous. The converse fails (for instance \(y=|x|\) at \(0\)).

4.2 Sum rule

Statement. If \(f\) and \(g\) are differentiable at \(x\), then \(f+g\) is differentiable at \(x\) and

\[ (f+g)'(x) = f'(x) + g'(x). \]
Proof

Let \(F = f+g\), so \(F(x) = f(x)+g(x)\). For \(h \neq 0\),

\[ \frac{F(x+h)-F(x)}{h} = \frac{f(x+h)+g(x+h) - f(x) - g(x)}{h}. \]

Step 1 (regroup). Put the \(f\)-terms and \(g\)-terms together:

\[ = \frac{\bigl[f(x+h)-f(x)\bigr] + \bigl[g(x+h)-g(x)\bigr]}{h} = \frac{f(x+h)-f(x)}{h} + \frac{g(x+h)-g(x)}{h}. \]

Step 2 (sum law). Both quotients have limits \(f'(x)\) and \(g'(x)\), so by the sum law for limits,

\[ F'(x) = \lim_{h\to0}\left[\frac{f(x+h)-f(x)}{h} + \frac{g(x+h)-g(x)}{h}\right] = f'(x) + g'(x). \]

4.3 Difference rule

Statement. If \(f\) and \(g\) are differentiable at \(x\), then \(f-g\) is differentiable at \(x\) and \((f-g)'(x) = f'(x) - g'(x)\).

Proof

Let \(F = f-g\). For \(h\neq0\), regrouping as before,

\[ \frac{F(x+h)-F(x)}{h} = \frac{\bigl[f(x+h)-f(x)\bigr] - \bigl[g(x+h)-g(x)\bigr]}{h} = \frac{f(x+h)-f(x)}{h} - \frac{g(x+h)-g(x)}{h}. \]

By the difference law for limits (the sum law applied to the second term multiplied by \(-1\)),

\[ F'(x) = f'(x) - g'(x). \]

Since \(f - g = f + (-1)g\), this rule is not logically needed.

4.4 Constant multiple rule

Statement. If \(c \in \mathbb{R}\) is fixed and \(f\) is differentiable at \(x\), then \(cf\) is differentiable at \(x\) and

\[ (cf)'(x) = c\,f'(x). \]
Proof

Let \(F = cf\), so \(F(x) = c\,f(x)\). For \(h \neq 0\),

\[ \frac{F(x+h)-F(x)}{h} = \frac{c\,f(x+h) - c\,f(x)}{h} = \frac{c\bigl[f(x+h)-f(x)\bigr]}{h} = c\cdot\frac{f(x+h)-f(x)}{h}, \]

factoring out \(c\). By the constant multiple law for limits, \(\lim_{h\to0} c\,Q(h) = c\,\lim_{h\to0}Q(h)\) for the difference quotient \(Q\) of \(f\), so

\[ F'(x) = c \lim_{h\to0}\frac{f(x+h)-f(x)}{h} = c\,f'(x). \]

4.5 Why the lemma \(\lim_{h\to0}f(x+h)=f(x)\) is recorded here

Section 3.2's product and quotient rules need it.

4.6 Assembly: differentiating a polynomial

Combining §2, §3 and this card, for \(p(x) = c_nx^{n} + c_{n-1}x^{n-1} + \cdots + c_1x + c_0\),

\[ p'(x) = n\,c_nx^{\,n-1} + (n-1)c_{n-1}x^{\,n-2} + \cdots + 2c_2x + c_1, \]

by differentiating term by term, pulling out coefficients, and dropping \(c_0\).

5. Extending the power rule: negative and fractional exponents

We extend the power rule to negative integer exponents and to \(n\)-th roots. The rules for \(x^{1/n}\) and \(e^{x}\) each rest on one limit (\(\lim_{h\to0}\bigl((x+h)^{1/n}-x^{1/n}\bigr)/h\) and \(\lim_{h\to0}(a^{h}-1)/h\)):

\[ \frac{d}{dx}\bigl[x^{-n}\bigr] = -n\,x^{-n-1}, \qquad \frac{d}{dx}\bigl[x^{1/n}\bigr] = \tfrac{1}{n}\,x^{\frac1n-1}, \]

5.1 The reciprocal rule, by the limit definition

Special case: \(r(x) = \dfrac{1}{x}\), \(x \neq 0\).

Proof that \(\dfrac{d}{dx}\Bigl[\dfrac1x\Bigr] = -\dfrac{1}{x^{2}}\)

Fix \(x \neq 0\) and take \(|h| < |x|/2\), so \(x + h \neq 0\). Then

\[ \frac{r(x+h)-r(x)}{h} = \frac{\dfrac{1}{x+h} - \dfrac{1}{x}}{h}. \]

Step 1 (common denominator).

\[ \frac{1}{x+h} - \frac{1}{x} = \frac{x - (x+h)}{x(x+h)} = \frac{-h}{x(x+h)}. \]

Step 2 (divide by \(h\), cancel). For \(h \neq 0\),

\[ \frac{r(x+h)-r(x)}{h} = \frac{-h}{x(x+h)}\cdot\frac{1}{h} = \frac{-1}{x(x+h)}. \]

Step 3 (limit). The map \(y \mapsto \dfrac{-1}{xy}\) is a rational function of \(y\), nonzero at \(y = x\). By the quotient law (with the sum law to get \(\lim_{h\to0}(x+h) = x\)),

\[ r'(x) = \lim_{h\to0}\frac{-1}{x(x+h)} = \frac{-1}{x\cdot x} = -\frac{1}{x^{2}}. \]

In exponent notation, \(\dfrac{d}{dx}\bigl[x^{-1}\bigr] = -x^{-2}\), matching \(-n x^{-n-1}\) at \(n=1\).

5.2 The negative-integer power rule

Statement. For every positive integer \(n\) and every \(x \neq 0\),

\[ \frac{d}{dx}\bigl[x^{-n}\bigr] = -n\,x^{-n-1}, \qquad \text{equivalently} \qquad \frac{d}{dx}\left[\frac{1}{x^{n}}\right] = -\frac{n}{x^{\,n+1}}. \]

Writing \(x^{-n} = \dfrac{1}{x^{n}}\) and applying the quotient rule to \(\dfrac{1}{x^{n}}\) gives \(\dfrac{0\cdot x^{n} - 1\cdot nx^{n-1}}{x^{2n}} = -nx^{-n-1}\).

Proof (from the definition)

Fix \(x \neq 0\) and \(n\), let \(f(x) = x^{-n} = 1/x^{n}\), and take \(h \neq 0\) with \(x+h \neq 0\). The quotient is

\[ \frac{f(x+h)-f(x)}{h} = \frac{\dfrac{1}{(x+h)^{n}} - \dfrac{1}{x^{n}}}{h}. \]

Step 1 (common denominator).

\[ \frac{1}{(x+h)^{n}} - \frac{1}{x^{n}} = \frac{x^{n} - (x+h)^{n}}{x^{n}(x+h)^{n}}. \]

Step 2 (expand \((x+h)^{n}\); factor out \(h\)). By §3, \((x+h)^{n} = x^{n} + h\,B\) where \(B = n x^{n-1} + \binom{n}{2}x^{n-2}h + \cdots + n x h^{n-2} + h^{n-1}\). Therefore

\[ x^{n} - (x+h)^{n} = -h\,B. \]

Step 3 (divide by \(h\), cancel).

\[ \frac{f(x+h)-f(x)}{h} = \frac{-h\,B}{x^{n}(x+h)^{n}}\cdot\frac{1}{h} = \frac{-B}{x^{n}(x+h)^{n}}. \]

Step 4 (let \(h \to 0\)). \(B \to n x^{n-1}\) (each term but the first carries an \(h\)), and \((x+h)^{n} \to x^{n}\) because \(t\mapsto t^{n}\) is a product of \(n\) copies of \(t\), so the product law gives \(\lim (x+h)^{n} = x^{n}\). By the quotient law (denominator limit \(x^{n}\cdot x^{n} = x^{2n} \neq 0\)),

\[ f'(x) = \frac{-\,n x^{n-1}}{x^{n}\cdot x^{n}} = -n\,\frac{x^{n-1}}{x^{2n}} = -n\,x^{\,n-1-2n} = -n\,x^{-n-1}. \]

Sign check. The minus sign comes from the reversal \(x^{n}-(x+h)^{n}\), not the exponent: for \(n=1\) we recover \(-x^{-2}\), and for \(n=2\), \(\dfrac{d}{dx}\bigl[x^{-2}\bigr] = -2x^{-3}\), i.e. \(\dfrac{d}{dx}\bigl[1/x^{2}\bigr] = -2/x^{3}\), agreeing with the quotient rule of Section 3.2 applied to \(1/x^{n}\).

Section 3.2's quotient rule gives the same result.

5.3 The root rule: \(\dfrac{d}{dx}\bigl[x^{1/n}\bigr]\)

Statement. Let \(n \ge 2\) be an integer and \(f(x) = x^{1/n} = \sqrt[n]{x}\). For \(x > 0\),

\[ \frac{d}{dx}\bigl[x^{1/n}\bigr] = \frac{1}{n}\,x^{\frac{1}{n}-1}, \qquad\text{i.e.}\qquad \frac{d}{dx}\bigl[\sqrt[n]{x}\bigr] = \frac{1}{n\sqrt[n]{x^{\,n-1}}}. \]

The domain of \(\sqrt[n]{x}\) is \([0,\infty)\) for even \(n\) and \(\mathbb{R}\) for odd \(n\); the proof below treats \(x > 0\). For odd \(n\), the same formula also holds for \(x < 0\); at \(x=0\), no finite derivative exists.

Proof (rationalising identity for \(n\)-th roots)

Fix \(x > 0\) and take \(h \neq 0\) with \(x + h > 0\). Put \(a = (x+h)^{1/n}\), \(b = x^{1/n}\), both positive, so \(a^{n} - b^{n} = x + h - x = h\). The key identity is

\[ a^{n} - b^{n} = (a-b)\bigl(a^{n-1} + a^{n-2}b + a^{n-3}b^{2} + \cdots + ab^{\,n-2} + b^{\,n-1}\bigr). \]

(The right side telescopes to \(a^{n} - b^{n}\); for \(n=2\) it is \(a^{2}-b^{2} = (a-b)(a+b)\).) Therefore

\[ h = (a-b)\,S, \qquad S := a^{n-1} + a^{n-2}b + \cdots + b^{\,n-1}, \]

a sum of \(n\) positive terms. Since \(h \neq 0\), \(a \neq b\), so \(S \neq 0\) and we may divide:

\[ a - b = \frac{h}{S}. \]

Step 1 (rewrite the difference quotient).

\[ \frac{f(x+h)-f(x)}{h} = \frac{a-b}{h} = \frac{1}{S} = \frac{1}{a^{n-1} + a^{n-2}b + \cdots + ab^{\,n-2} + b^{\,n-1}}. \]

Step 2 (let \(h\to0\)). \(x + h \to x\), so \(a = (x+h)^{1/n} \to x^{1/n} = b\) by continuity of the positive \(n\)-th root. Each of the \(n\) terms of \(S\) tends to \(b^{\,n-1}\), and by the sum and constant-multiple laws

\[ S \longrightarrow \underbrace{b^{\,n-1} + b^{\,n-1} + \cdots + b^{\,n-1}}_{n \text{ terms}} = n\,b^{\,n-1} = n\,x^{\frac{n-1}{n}}. \]

Step 3 (quotient law). The limit of \(S\) is \(n x^{(n-1)/n} > 0\), so

\[ f'(x) = \frac{1}{\,n\,x^{\frac{n-1}{n}}\,} = \frac{1}{n}\,x^{-\frac{n-1}{n}} = \frac{1}{n}\,x^{\frac{1}{n}-1}, \]

because \(-\dfrac{n-1}{n} = \dfrac{1-n}{n} = \dfrac1n - 1\). This is the claimed \(\tfrac1n x^{1/n - 1}\).

Worked root cases. For \(n = 2\): \(\dfrac{d}{dx}\bigl[\sqrt{x}\bigr] = \tfrac12 x^{-1/2} = \dfrac{1}{2\sqrt{x}}\). For \(n = 3\): \(\dfrac{d}{dx}\bigl[\sqrt[3]{x}\bigr] = \tfrac13 x^{-2/3} = \dfrac{1}{3\sqrt[3]{x^{2}}}\).

Proof sketch note

First, \(t \mapsto t^{n}\) and \(t \mapsto t^{1/n}\) are continuous on \((0,\infty)\), so \(x + h \to x\) implies \((x+h)^{1/n} \to x^{1/n}\). Second, at \(x=0\) the difference quotient is \(h^{1/n}/h = h^{1/n - 1}\), which tends to \(+\infty\) for \(n > 1\), so \(\sqrt[n]{x}\) has a vertical tangent there.

5.4 Rational powers, for reference

Combining §5.3 with the chain rule of Section 3.4 extends the rule to \(x^{m/n} = \bigl(x^{1/n}\bigr)^{m}\): for \(x>0\) and integers \(m, n\) with \(n \ge 1\),

\[ \frac{d}{dx}\bigl[x^{m/n}\bigr] = \frac{m}{n}\,x^{\frac{m}{n}-1}. \]

It holds for every constant exponent \(r \in \mathbb{R}\) where \(x^{r}\) is differentiable; the irrational case needs logarithms. Proved here for integers (§3, §5.2) and \(1/n\) (§5.3).

6. The exponential rules: \(\dfrac{d}{dx}\bigl[e^{x}\bigr] = e^{x}\) and \(\dfrac{d}{dx}\bigl[a^{x}\bigr] = a^{x}\ln a\)

An exponential function is \(f(x) = a^{x}\), \(a > 0\). The natural exponential \(f(x) = e^{x}\), \(e = 2.718281828\ldots\), is the unique base whose tangent at \(x=0\) has slope \(1\).

6.1 The number \(e\), and the one limit the whole rule rests on

Convention. The number \(e\) is defined by \(\lim_{h\to0}(e^{h}-1)/h = 1\), and \(\ln\) is the inverse of \(e^{x}\). The identity \(\lim_{h\to0}(a^{h}-1)/h = \ln a\) below is then a theorem, not a definition.

Equivalently, the graph of \(y = e^{x}\) crosses the \(y\)-axis with slope \(1\):

\[ \lim_{h \to 0}\frac{e^{h} - 1}{h} = 1. \]

\(e\) is chosen so this limit is \(1\); numerically \(h = 0.1, 0.01, 0.001\) gives \((e^{h}-1)/h \approx 1.0517, 1.0050, 1.0005\). For general \(a>0\) the analogous limit equals \(\ln a\), a theorem because \(a \mapsto \ln a\) inverts \(e^{x}\):

\[ \lim_{h\to0}\frac{a^{h}-1}{h} = \ln a. \]

The limit is \(1\) exactly when \(a = e\). Distinct bases give distinct slopes because \(\ln\) is strictly increasing: \(a_2>a_1>0\) implies \(\ln(a_2/a_1)>0\).

Proof that \(\dfrac{d}{dx}\bigl[e^{x}\bigr] = e^{x}\)

Let \(f(x) = e^{x}\) and fix \(x\). The quotient is

\[ \frac{f(x+h)-f(x)}{h} = \frac{e^{\,x+h} - e^{x}}{h}. \]

Step 1 (the index law). Since \(e^{x+h} = e^{x}e^{h}\),

\[ \frac{e^{\,x+h} - e^{x}}{h} = \frac{e^{x}e^{h} - e^{x}}{h} = \frac{e^{x}\bigl(e^{h}-1\bigr)}{h} = e^{x}\cdot\frac{e^{h}-1}{h}. \]

Step 2 (constant multiple law for limits).

\[ \lim_{h\to0} e^{x}\cdot\frac{e^{h}-1}{h} = e^{x}\cdot\lim_{h\to0}\frac{e^{h}-1}{h}. \]

Step 3 (evaluate the remaining limit). By the defining property of \(e\), \(\lim_{h\to0}\dfrac{e^{h}-1}{h} = 1\). Therefore

\[ f'(x) = e^{x}\cdot 1 = e^{x}. \]

So \(\dfrac{d}{dx}\bigl[e^{x}\bigr] = e^{x}\) for all real \(x\).

6.2 The general base, and where \(\ln a\) comes from

Statement. For every base \(a > 0\),

\[ \frac{d}{dx}\bigl[a^{x}\bigr] = a^{x}\ln a. \]
Proof 1 (directly from the limit definition)

Let \(f(x) = a^{x}\) with \(a>0\), and fix \(x\). Using \(a^{\,x+h} = a^{x}a^{h}\),

\[ \frac{a^{\,x+h}-a^{x}}{h} = \frac{a^{x}a^{h}-a^{x}}{h} = a^{x}\cdot\frac{a^{h}-1}{h}. \]

By the constant multiple law and the limit of §6.1,

\[ f'(x) = a^{x}\cdot\lim_{h\to0}\frac{a^{h}-1}{h} = a^{x}\ln a. \]

So \(\ln a\) is the slope of \(y=a^{x}\) at \(x=0\). For \(a\neq1\), put \(c=\ln a\neq0\); since \(a^h=e^{ch}\), \[\frac{a^h-1}{h}=c\,\frac{e^{ch}-1}{ch}\longrightarrow c=\ln a,\] using the defining limit for \(e\), with \(ch\to0\). If \(a=1\) the quotient is zero, agreeing with \(\ln1=0\).

Proof 2 (rewrite \(a^{x}\) with base \(e\); the source of \(\ln a\))

Since \(e^{x}\) and \(\ln x\) are inverses, \(a = e^{\ln a}\). By the index law \(e^{uv} = \bigl(e^{u}\bigr)^{v}\),

\[ a^{x} = \bigl(e^{\ln a}\bigr)^{x} = e^{\,x\ln a}. \]

Write \(u(x) = x\ln a\), so \(a^{x} = e^{u(x)}\), with outer function \(e^{u}\) and inner function \(u = x\ln a\). By the chain rule of Section 3.4,

\[ \frac{d}{dx}\bigl[e^{\,u(x)}\bigr] = e^{\,u(x)}\cdot u'(x) = e^{\,x\ln a}\cdot \ln a = a^{x}\ln a, \]

because \(u'(x) = \ln a\) is the derivative of the linear function \(x \mapsto x\ln a\) (constant multiple rule on \(\dfrac{d}{dx}(x) = 1\)).

Where the factor \(\ln a\) comes from: the exponent is \(x\ln a\), so the outer derivative supplies \(e^{x\ln a} = a^{x}\) and the inner derivative contributes the stretch factor \(\ln a\). If \(a = e\) then \(\ln a = 1\) and no stretching occurs. If \(a > 1\) the derivative \(a^{x}\ln a\) is positive: it exceeds \(a^{x}\) only when \(a > e\), equals it when \(a=e\), and is smaller when \(1 < a < e\); if \(0 < a < 1\) then \(\ln a < 0\) and \(a^{x}\) is decreasing at rate \(|{\ln a}|\,a^{x}\).

Example 2

Compare the two exponential rules on a concrete base. Verify \(\dfrac{d}{dx}\bigl[2^{x}\bigr] = 2^{x}\ln 2\) in two ways: once by the definition and once through base \(e\).

Show answerHide answer
  1. By the definition. With \(f(x) = 2^{x}\), \(\dfrac{f(x+h)-f(x)}{h} = \dfrac{2^{x}2^{h} - 2^{x}}{h} = 2^{x}\cdot\dfrac{2^{h}-1}{h}\).
  2. By the constant multiple law, \(f'(x) = 2^{x}\lim_{h\to0}\dfrac{2^{h}-1}{h}\).
  3. The remaining limit is \(\ln 2 \approx 0.6931\) (numerically \(\frac{2^{0.001}-1}{0.001}\approx 0.693387\)), so \(f'(x) = 2^{x}\ln 2\).
  4. Through base \(e\). Write \(2^{x} = e^{\,x\ln 2}\), with outer function \(e^{u}\) and inner function \(u = x\ln 2\).
  5. Chain rule: \(\dfrac{d}{dx}\bigl[e^{\,x\ln 2}\bigr] = e^{\,x\ln 2}\cdot \ln 2 = 2^{x}\ln 2\), using \(u' = \ln 2\).
  6. At \(x=0\) both routes give slope \(\ln 2 \approx 0.6931 < 1\) for \(y=2^{x}\) at the point \((0,1)\), so \(2^{x}\) is "gentler" than \(e^{x}\).
Answer: \(\dfrac{d}{dx}\bigl[2^{x}\bigr] = 2^{x}\ln 2\), confirmed by both routes.

6.3 One more consistency check: slope at zero of \(e^{kx}\)

For constant \(k\), \(\dfrac{d}{dx}\bigl[e^{kx}\bigr] = k\,e^{kx}\). For \(k=2\), directly from the definition:

\[ \frac{e^{2(x+h)} - e^{2x}}{h} = \frac{e^{2x}e^{2h} - e^{2x}}{h} = e^{2x}\cdot\frac{e^{2h}-1}{h} = e^{2x}\cdot 2\cdot\frac{e^{2h}-1}{2h} \longrightarrow e^{2x}\cdot 2\cdot 1 = 2e^{2x}, \]

recognising \(\dfrac{e^{2h}-1}{2h}\) as the §6.1 quotient at \(2h \to 0\).

7. Worked examples

Example 3

Differentiate \(f(x) = 6x^{2}\) and then \(f(x) = 6x^{2} - 2x + 3\).

Show answerHide answer
  1. For \(f(x) = 6x^{2}\): a constant \(6\) times the power \(x^{2}\), so start from the power rule with \(n = 2\): \(\dfrac{d}{dx}\bigl[x^{2}\bigr] = 2x^{2-1} = 2x\).
  2. Apply the constant multiple rule with \(c = 6\): \(f'(x) = 6\cdot\dfrac{d}{dx}\bigl[x^{2}\bigr] = 6\cdot 2x = 12x\).
  3. For \(f(x) = 6x^{2}-2x+3\): split term by term via the sum and difference rules, \(f' = \dfrac{d}{dx}\bigl[6x^{2}\bigr] - \dfrac{d}{dx}\bigl[2x\bigr] + \dfrac{d}{dx}\bigl[3\bigr]\).
  4. First term (power + constant multiple, \(n=2\)): \(\dfrac{d}{dx}\bigl[6x^{2}\bigr] = 6\cdot 2x^{1} = 12x\).
  5. Second term (power rule with \(n = 1\), then constant multiple): \(\dfrac{d}{dx}\bigl[2x\bigr] = 2\cdot\dfrac{d}{dx}\bigl[x^{1}\bigr] = 2\cdot 1x^{0} = 2\).
  6. Third term (constant rule): \(\dfrac{d}{dx}\bigl[3\bigr] = 0\). Adding the pieces, \(f'(x) = 12x - 2 + 0\).
  7. Check at \(x = 1\). The formula gives \(f'(1) = 10\). With \(h = 0.001\), \(f(1.001) = 6(1.001)^{2} - 2(1.001) + 3 = 6(1.002001) - 2.002 + 3 = 7.010006\), \(f(1) = 7\), and the quotient is \(0.010006/0.001 = 10.006 \to 10\).
Answer: \(\dfrac{d}{dx}\bigl[6x^{2}\bigr] = 12x\), and \(\dfrac{d}{dx}\bigl[6x^{2}-2x+3\bigr] = 12x - 2\).
Example 4

Differentiate \(g(x) = \dfrac{x^{4} - 3x^{3} + x^{2} - 2x + 5}{x^{2}}\), splitting the fraction first.

Show answerHide answer
  1. Prepare the function. The domain is \(x \neq 0\). Divide each term of the numerator by \(x^{2}\), using the index law \(x^{a}/x^{b} = x^{a-b}\): \[ g(x) = \frac{x^{4}}{x^{2}} - \frac{3x^{3}}{x^{2}} + \frac{x^{2}}{x^{2}} - \frac{2x}{x^{2}} + \frac{5}{x^{2}} = x^{2} - 3x + 1 - 2x^{-1} + 5x^{-2}. \]
  2. Differentiate term by term (sum and difference rules), pulling out coefficients (constant multiple rule): \[ g'(x) = \frac{d}{dx}\bigl[x^{2}\bigr] - 3\frac{d}{dx}\bigl[x\bigr] + \frac{d}{dx}\bigl[1\bigr] - 2\frac{d}{dx}\bigl[x^{-1}\bigr] + 5\frac{d}{dx}\bigl[x^{-2}\bigr]. \]
  3. Power rule with \(n=2\): \(\dfrac{d}{dx}\bigl[x^{2}\bigr] = 2x\).
  4. Power rule with \(n=1\): \(\dfrac{d}{dx}\bigl[x\bigr] = 1x^{0} = 1\), so the second term is \(-3\cdot 1 = -3\).
  5. Constant rule: \(\dfrac{d}{dx}\bigl[1\bigr] = 0\).
  6. Negative power rule with \(n=1\) (§5.2): \(\dfrac{d}{dx}\bigl[x^{-1}\bigr] = -1\,x^{-1-1} = -x^{-2}\), so the fourth term is \(-2\cdot(-x^{-2}) = +2x^{-2}\).
  7. Negative power rule with \(n=2\): \(\dfrac{d}{dx}\bigl[x^{-2}\bigr] = -2x^{-2-1} = -2x^{-3}\), so the fifth term is \(5\cdot(-2x^{-3}) = -10x^{-3}\).
  8. Collect. \[ g'(x) = 2x - 3 + 0 + 2x^{-2} - 10x^{-3} = 2x - 3 + \frac{2}{x^{2}} - \frac{10}{x^{3}}. \]
  9. Check at \(x = 1\). The formula gives \(g'(1) = 2 - 3 + 2 - 10 = -9\). With \(h = 0.001\), the numerator of \(g(1.001)\) is \(1.001^{4} - 3(1.001)^{3} + 1.001^{2} - 2(1.001) + 5\), and using \(1.001^{2} = 1.002001\), \(1.001^{3} = 1.003003001\) and \(1.001^{4} = 1.004006004001\), this numerator is \(1.004006 - 3.009009 + 1.002001 - 2.002 + 5 = 1.994998\). The denominator is \(1.001^{2} = 1.002001\), so \(g(1.001) = 1.994998/1.002001 = 1.991014\), while \(g(1) = 2\). The difference quotient is \((1.991014-2)/0.001 = -8.986\); at \(h = 10^{-6}\) it is \(-8.999986\), converging to \(-9\) as predicted. The error \(\approx (h/2)g''(1) = 0.014\).
  10. Why splitting is the better route here. The quotient rule of Section 3.2 with \(u = x^{4}-3x^{3}+x^{2}-2x+5\) and \(v=x^{2}\) gives \(g' = \dfrac{u'v - uv'}{v^{2}}\), whose numerator must then be simplified by cancelling the common factor \(x\) (leaving \(x^{3}\)); splitting replaces that by five one-line power-rule applications and exposes the negative exponents \(x^{-1}, x^{-2}\).
Answer: \(g'(x) = 2x - 3 + \dfrac{2}{x^{2}} - \dfrac{10}{x^{3}}\), valid for \(x \neq 0\).
Example 5

Differentiate \(f(x) = 3x^{2} + 2e^{x}\).

Show answerHide answer
  1. Use the sum rule: \(f'(x) = \dfrac{d}{dx}\bigl[3x^{2}\bigr] + \dfrac{d}{dx}\bigl[2e^{x}\bigr]\).
  2. First term — constant multiple with \(c=3\), then the power rule with \(n=2\): \(\dfrac{d}{dx}\bigl[3x^{2}\bigr] = 3\cdot 2x^{2-1} = 6x\).
  3. Second term — constant multiple with \(c=2\), then the exponential rule \(\dfrac{d}{dx}\bigl[e^{x}\bigr] = e^{x}\): \(\dfrac{d}{dx}\bigl[2e^{x}\bigr] = 2e^{x}\).
  4. Combine: \(f'(x) = 6x + 2e^{x}\).
  5. Check at \(x = 0\). Formula: \(f'(0) = 0 + 2(1) = 2\). With \(h=0.001\), \(f(0.001) = 3(10^{-6}) + 2e^{0.001} = 0.000003 + 2.0020010 = 2.0020040\) and \(f(0) = 2\), so the quotient is \(0.0020040/0.001 = 2.0040\). The gap from \(f'(0)=2\) is the expected forward-difference error, of size comparable to \(h\).
Answer: \(f'(x) = 6x + 2e^{x}\).
Example 6

Differentiate \(f(x) = \dfrac{2x^{4} - 3x^{2} - xe^{x}}{x}\), for \(x \neq 0\).

Show answerHide answer
  1. Split the fraction. For \(x \neq 0\), divide each term by \(x\): \[ f(x) = \frac{2x^{4}}{x} - \frac{3x^{2}}{x} - \frac{xe^{x}}{x} = 2x^{3} - 3x - e^{x}. \]
  2. Differentiate term by term (sum and difference rules): \(f'(x) = \dfrac{d}{dx}\bigl[2x^{3}\bigr] - \dfrac{d}{dx}\bigl[3x\bigr] - \dfrac{d}{dx}\bigl[e^{x}\bigr]\).
  3. First term — constant multiple, then power rule with \(n=3\): \(\dfrac{d}{dx}\bigl[2x^{3}\bigr] = 2\cdot 3x^{2} = 6x^{2}\).
  4. Second term — constant multiple, then power rule with \(n=1\): \(\dfrac{d}{dx}\bigl[3x\bigr] = 3\cdot 1 = 3\).
  5. Third term — exponential rule: \(\dfrac{d}{dx}\bigl[e^{x}\bigr] = e^{x}\).
  6. Collect: \(f'(x) = 6x^{2} - 3 - e^{x}\).
  7. Check at \(x=1\). The formula gives \(f'(1) = 6 - 3 - e = 3 - 2.71828 = 0.28172\). With \(h = 0.0001\), \(f(1) = 2 - 3 - e = -3.7182818\) and \(f(1.0001) = \frac{2(1.0001)^{4} - 3(1.0001)^{2} - 1.0001\,e^{1.0001}}{1.0001}\). The pieces are \((1.0001)^{2} = 1.00020001\), \((1.0001)^{4} = 1.00040006\) and \(e^{1.0001} = 2.7185537\), so the numerator is \(2.00080012 - 3.00060003 - 2.7188255 = -3.7186254\). Since \(f(1.0001) = -3.7182536\), the quotient is \((-3.7182536 + 3.7182818)/0.0001 = 0.2822\), close to \(0.2817\).
Answer: \(f'(x) = 6x^{2} - 3 - e^{x}\) for \(x \neq 0\). The simplified expression \(2x^{3}-3x-e^{x}\) extends the original function to \(x=0\), but the original quotient and its derivative remain undefined there.
Example 7

Find the points on the curve \(y = x^{4} - 6x^{2} + 4\) at which the tangent line is horizontal.

Show answerHide answer
  1. Translate the condition. A tangent is horizontal exactly when its slope is \(0\), and the slope at \(x\) is \(\dfrac{dy}{dx}\). So solve \(\dfrac{dy}{dx} = 0\).
  2. Compute the derivative term by term (sum and difference rules): \[ \frac{dy}{dx} = \frac{d}{dx}\bigl[x^{4}\bigr] - 6\frac{d}{dx}\bigl[x^{2}\bigr] + \frac{d}{dx}\bigl[4\bigr]. \]
  3. Power rule with \(n=4\): \(\dfrac{d}{dx}\bigl[x^{4}\bigr] = 4x^{3}\).
  4. Power rule with \(n=2\), with the constant multiple rule: \(6\dfrac{d}{dx}\bigl[x^{2}\bigr] = 6\cdot 2x = 12x\).
  5. Constant rule: \(\dfrac{d}{dx}\bigl[4\bigr] = 0\). Hence \(\dfrac{dy}{dx} = 4x^{3} - 12x\).
  6. Solve \(\dfrac{dy}{dx}=0\). Factor: \(4x^{3}-12x = 4x(x^{2}-3) = 0\), so \(x = 0\) or \(x^{2} = 3\), i.e. \(x = 0,\ \sqrt{3},\ -\sqrt{3}\).
  7. Find the \(y\)-coordinates from \(y = x^{4}-6x^{2}+4\). At \(x=0\): \(y = 0 - 0 + 4 = 4\), giving \((0,4)\). At \(x^{2}=3\): \(y = 3^{2} - 6(3) + 4 = 9 - 18 + 4 = -5\), giving \((\sqrt{3},-5)\) and \((-\sqrt{3},-5)\).
  8. Check. At \(x=\sqrt{3}\), \(4x^{3}-12x = 4(3\sqrt{3}) - 12\sqrt{3} = 12\sqrt{3}-12\sqrt{3} = 0\), and at \(x=0\) it is \(0\). These checks confirm the horizontal tangents at the three stated points.
Answer: the tangent is horizontal at \((0,4)\), \((\sqrt{3},-5)\) and \((-\sqrt{3},-5)\).
Example 8

Higher derivatives. For \(f(x) = x^{3} - 6x^{2} + 5x - 2\), find \(f'\), \(f''\), \(f'''\) and \(f^{(4)}\), and find where \(f''\) vanishes.

Show answerHide answer
  1. First derivative — difference, constant multiple and power rules: \(f'(x) = 3x^{2} - 6(2x) + 5(1) - 0 = 3x^{2} - 12x + 5\).
  2. Second derivative (differentiate \(f'\), \(\dfrac{d^2y}{dx^2}\)): \(f''(x) = 3(2x) - 12(1) + 0 = 6x - 12\).
  3. Third derivative (\(n=3\)): \(f'''(x) = 6 - 0 = 6\), a constant.
  4. Fourth derivative: \(f^{(4)}(x) = \dfrac{d}{dx}(6) = 0\) by the constant rule, and hence \(f^{(n)}(x) = 0\), i.e. \(f^{(n)} \equiv 0\), for every \(n \ge 4\).
  5. Reading the answers. \(f''(x) = 6x-12\) has one zero at \(x = 2\), and \(\bigl(2, f(2)\bigr) = \bigl(2, 8 - 24 + 10 - 2\bigr) = (2,-8)\).
Answer: \(f'(x) = 3x^{2}-12x+5\), \(f''(x) = 6x-12\), \(f'''(x) = 6\), \(f^{(4)}(x) = 0\), and \(f''\) vanishes at \(x = 2\), the point \((2,-8)\).

8. Common mistakes, and a recap of every rule

Mistake 1

Treating \(x^{n}\) as if the exponent were the variable — applying the "exponential" pattern \(\frac{d}{dx}(a^{x}) = a^{x}\ln a\) to a power, or the power pattern to an exponential.

Wrong: \(\dfrac{d}{dx}\bigl[x^{3}\bigr] = x^{3}\ln x\), or \(\dfrac{d}{dx}\bigl[e^{x}\bigr] = x e^{x-1}\).

Right: \(\dfrac{d}{dx}\bigl[x^{3}\bigr] = 3x^{2}\) (exponent drops in front and decreases by one) and \(\dfrac{d}{dx}\bigl[e^{x}\bigr] = e^{x}\) (the function reproduces itself). Rule of thumb: if only the base varies, use the power rule; if only the exponent varies, use the exponential rule. If both vary, see Section 3.7.

Mistake 2

Dropping the factor \(\ln a\) when differentiating \(a^{x}\). The derivative of \(e^{x}\) is \(e^{x}\) only because \(\ln e = 1\); a general base keeps its factor.

Wrong: \(\dfrac{d}{dx}\bigl[5^{x}\bigr] = 5^{x}\).

Right: \(\dfrac{d}{dx}\bigl[5^{x}\bigr] = 5^{x}\ln 5 \approx 1.6094\cdot 5^{x}\). The factor comes from \(5^{x} = e^{x\ln 5}\), whose inner derivative is \(\ln 5\).

Mistake 3

Assuming the power rule requires \(n\) to be a positive integer. The formula \(\frac{d}{dx}(x^{n}) = nx^{n-1}\) holds for every integer \(n\) (negative included, on \(x \neq 0\)), for \(n = 1/k\), and in fact for every real constant \(n\) wherever \(x^{n}\) is defined and differentiable.

Wrong: "I cannot differentiate \(x^{-3}\) or \(\sqrt{x}\) with the power rule."

Right: \(\dfrac{d}{dx}\bigl[x^{-3}\bigr] = -3x^{-4}\) and \(\dfrac{d}{dx}\bigl[\sqrt{x}\bigr] = \dfrac{d}{dx}\bigl[x^{1/2}\bigr] = \tfrac12 x^{-1/2} = \dfrac{1}{2\sqrt{x}}\) for \(x>0\). What matters is the domain (\(x \neq 0\) for negative powers, \(x>0\) for the fractional formula), not integrality of the exponent.

Mistake 4

Sign errors in the negative-power rule. Two minus signs are in play — the one in the exponent \((-n)\) and the one in the derivative \(\frac{d}{dx}\bigl[x^{-n}\bigr] = -n x^{-n-1}\) (that is, \((-n x^{-n-1})\)) — and they must not be conflated. The exponent decreases by one, from \(-n\) to \(-n-1\), which is more negative.

Wrong: \(\dfrac{d}{dx}\bigl[x^{-2}\bigr] = -2x^{-1}\) (exponent moved the wrong way), or \(\dfrac{d}{dx}\bigl[x^{-2}\bigr] = 2x^{-3}\) (sign of the coefficient lost), or \(\dfrac{d}{dx}\bigl[1/x\bigr] = 1/x^{2}\) (sign lost).

Right: \(\dfrac{d}{dx}\bigl[x^{-2}\bigr] = -2x^{-3} = -\dfrac{2}{x^{3}}\) and \(\dfrac{d}{dx}\bigl[1/x\bigr] = -x^{-2} = -\dfrac{1}{x^{2}}\). The minus sign in \(-n x^{-n-1}\) comes from the reversal \(x^{n} - (x+h)^{n}\) in §5.2.

Mistake 5 (smaller, but common)

Cancelling the constant term's derivative incorrectly — writing \(\frac{d}{dx}(3) = 3\) or forgetting that a standalone constant contributes nothing. Right: \(\frac{d}{dx}(3) = 0\), so \(\frac{d}{dx}\bigl[6x^{2}-2x+3\bigr] = 12x-2\), not \(12x-2+3\). Note \(\frac{d}{dx}\bigl[6x^{2}\bigr] = 6\cdot 2x\), and \(2\cdot 3 = 6\). Also, \(\frac{d}{dx}\bigl[x^{2}\bigr]\) at \(x=3\) is \(6\) — a number, not the function \(2x\).

8.1 Rules recap

Every rule with its hypothesis: \(c\) constant, \(f, g\) differentiable at \(x\), \(a > 0\).

Rule Statement Conditions When to use
Constant \(\dfrac{d}{dx}(c) = 0\) \(c\) constant, any \(x\) A term with no \(x\); it drops out.
Power (positive integer \(n\)) \(\dfrac{d}{dx}\bigl[x^{n}\bigr] = nx^{n-1}\) \(n \in \{1,2,3,\dots\}\), all real \(x\) A constant power of \(x\): \(x^{7}\), \(x^{2}\), \(x = x^{1}\).
Constant multiple \(\dfrac{d}{dx}\bigl[c\,f(x)\bigr] = c\,f'(x)\) \(c\) constant, \(f\) differentiable at \(x\) Numerical coefficients: \(6x^{2}\), \(2e^{x}\), \(\tfrac{1}{3}x^{4}\).
Sum \(\dfrac{d}{dx}\bigl[f(x)+g(x)\bigr] = f'(x)+g'(x)\) \(f,g\) differentiable at \(x\) Adding terms; combining a polynomial with an exponential.
Difference \(\dfrac{d}{dx}\bigl[f(x)-g(x)\bigr] = f'(x)-g'(x)\) \(f,g\) differentiable at \(x\) Subtracted terms, as in \(x^{4}-6x^{2}+4\).
Negative power \(\dfrac{d}{dx}\bigl[x^{-n}\bigr] = -n\,x^{-n-1}\) \(n\) positive integer, \(x \neq 0\) Reciprocals like \(1/x^{2} = x^{-2}\).
Root (\(n\)-th root) \(\dfrac{d}{dx}\bigl[x^{1/n}\bigr] = \tfrac1n x^{\frac1n-1} = \dfrac{1}{n\sqrt[n]{x^{\,n-1}}}\) integer \(n \ge 2\), \(x > 0\) Radicals as powers: \(\sqrt{x} = x^{1/2}\), \(\sqrt[3]{x} = x^{1/3}\), \(x^{1/4} = \sqrt[4]{x}\).
Rational power (reference) \(\dfrac{d}{dx}\bigl[x^{m/n}\bigr] = \dfrac{m}{n}x^{\frac{m}{n}-1}\) integers \(m\), \(n \ge 1\), \(x > 0\) Fractional exponents. Only \(m=1\) is proved here (§5.3); the general case also needs the chain rule of Section 3.4.
Natural exponential \(\dfrac{d}{dx}\bigl[e^{x}\bigr] = e^{x}\) all real \(x\) Any \(e^{x}\); the derivative reproduces the function.
General exponential \(\dfrac{d}{dx}\bigl[a^{x}\bigr] = a^{x}\ln a\) base \(a > 0\), all real \(x\) Bases other than \(e\): \(2^{x}\), \(10^{x}\), \(5^{x}\).

8.2 Using the table: the standard three-step routine

  1. Rewrite the function as a sum of constant multiples of \(x^{n}\) and \(e^{x}\) (split fractions, simplify negative exponents, write roots as powers).
  2. Differentiate term by term with the sum and difference rules, pulling constants out with the constant multiple rule.
  3. Apply one rule per term — power rule, exponential rule or constant rule as appropriate — then collect like terms.

8.3 What comes next

Three gaps remain: (i) products such as \(\dfrac{d}{dx}\bigl[x^{2}e^{x}\bigr]\), which is not \(2x\cdot e^{x}\), need the product rule of Section 3.2; (ii) non-monomial quotients such as \(\dfrac{xe^{x}}{x-1}\) need the quotient rule; (iii) composites such as \(e^{3x^{2}}\) or \((2x-1)^{5}\) need the chain rule of Section 3.4.
