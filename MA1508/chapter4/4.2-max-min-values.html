Maximum and Minimum Values

Distinguish local from absolute extrema, find critical numbers, and compare candidates with endpoints. Textbook reading: Stewart §4.2 (pp. 262–270), with the MVT from §4.3 placed here as a bridge.

ONE EXAMPLE, BEFORE ANY THEORY

You can find the top of a hill without knowing the equation of the hillside: at the very top, the ground is flat. That one observation solves a surprising number of real problems.

A shop sells a widget at price \(p\) and makes profit \(P(p)\). Price it too low and each sale earns nothing; price it too high and nobody buys. If the profit is continuous on a closed bounded price interval, a best price exists. Only a differentiable interior optimum must have a flat tangent; the best price may instead be an endpoint.

This section makes "flat" precise with two theorems, and then says carefully where flat is not enough — and where the best value hides at an endpoint instead.

1. Definitions: absolute and local extrema

We begin with the precise vocabulary. Following Stewart, local extrema here are at interior points with a two-sided neighbourhood; endpoints are checked separately for absolute extrema.

Read it in 3 seconds

  • Absolute max / min: the best on the whole domain.
  • Local max / min: the best in a neighbourhood.
  • A local max can sit far below the absolute max.
  • Many local extrema can coexist.
\[ \textbf{Absolute maximum.} \text{ } f(c) \text{ is the absolute maximum of } f \text{ on a set } D \text{ if } f(c) \ge f(x) \text{ for every } x \in D. \]
\[ \textbf{Local maximum.} \text{ } f(c) \text{ is a local maximum if } f(c) \ge f(x) \text{ for every } x \text{ in some open interval containing } c. \]

The analogous definitions for absolute minimum and local minimum reverse the inequalities.

The word "local" means "compared with neighbours": a local maximum can be far below the global maximum elsewhere on the domain, and there can be many local maxima.

Example 1

For \(f(x)=x^{2}\) on \([-2,2]\), find the absolute and local extrema. Compare with \(f(x)=x^{3}\) on the same interval.

Show answerHide answer
  1. \(f(x)=x^{2}\): absolute (and local) minimum at \(x=0\), value \(0\); absolute maxima at both endpoints \(x=-2\) and \(x=2\), value \(4\).
  2. \(f(x)=x^{3}\): absolute minimum at \(x=-2\), value \(-8\); absolute maximum at \(x=2\), value \(8\). There is no local extremum at \(x=0\) even though the derivative is \(0\) there.
  3. Moral: a zero derivative alone does not make an extremum — the shape of the function matters.
Answer: \(x^{2}\) has a minimum at \(0\); \(x^{3}\) has no extremum at \(0\) despite \(f'(0)=0\).

2. The Extreme Value Theorem

Read it in 3 seconds

  • Here the minimum is interior, at \(f′=0\).
  • The maximum is at the endpoint \(b\).
  • Extrema can hide at endpoints — so the method checks them.
  • Drop continuity or closedness and the guarantee dies.
\[ \textbf{Extreme Value Theorem (EVT).} \text{ If } f \text{ is continuous on a closed interval } [a,b], \text{ then } f \text{ attains both an absolute maximum and an absolute minimum on } [a,b]. \]

Two hypotheses are essential:

  • Continuity. Without it, a function can jump past a candidate value without attaining it, or shoot to infinity.
  • Closed, bounded interval. On \((a,b)\) or \([a,\infty)\), a continuous function need not attain extrema: \(f(x)=x\) on \((0,1)\) has no maximum or minimum.
Why the interval matters

In data science, the closed-interval hypothesis appears when you restrict a parameter to a box \([\ell,u]\) — as in bounded optimization.

If the feasible set is open (say, a probability in \((0,1)\)), the optimum may occur only in the limit, and the EVT does not apply.

3. Fermat's theorem and critical numbers

\[ \textbf{Fermat's theorem.} \text{ If } c \text{ is an interior local extremum of } f \text{ and } f'(c) \text{ exists, then } f'(c)=0. \]

Read it in 3 seconds

  • \(y=x^{2}\): \(f′(0)=0\) and a minimum.
  • \(y=x^{3}\): \(f′(0)=0\) and no extremum at all.
  • Fermat’s theorem is one-way only.
  • \(f′=0\) lists candidates; the shape decides.
Proof sketch (local maximum case)

Assume \(f\) has a local maximum at \(c\). Then for \(x\) close to \(c\), \(f(x)-f(c)\le0\). For \(x>c\), the difference quotient \((f(x)-f(c))/(x-c)\le0\), so its limit as \(x\to c^{+}\) is \(\le0\). For \(x<c\), the quotient \((f(x)-f(c))/(x-c)\ge0\), so the left limit is \(\ge0\). Since \(f'(c)\) exists, both one-sided limits equal \(f'(c)\), forcing \(f'(c)=0\). The local-minimum case is symmetric.

Fermat's theorem says that interior local extrema occur where the derivative is zero or does not exist. Endpoints must be checked separately. This motivates the definition:

\[ \textbf{Critical number.} \text{ A critical number of } f \text{ is a number } c \text{ in the domain of } f \text{ such that } f'(c)=0 \text{ or } f'(c) \text{ does not exist.} \]
The converse is false

Fermat's theorem is one-way.

If \(f'(c)=0\), then \(c\) is a candidate, but it need not be an extremum: \(f(x)=x^{3}\) has \(f'(0)=0\) and no extremum at \(0\).

Finding candidates is cheap; deciding which are extrema is the rest of the chapter.

4. The Closed Interval Method

For a function continuous on a closed bounded interval, the EVT guarantees extrema, and Fermat identifies the interior candidates. When the critical numbers are finite and can be listed, the following method is a finite calculation:

Read it in 3 seconds

  • Step 1: critical numbers in \((a,b)\) — here only \(x=1\).
  • Step 2: evaluate \(f\) there and at both endpoints.
  • Step 3: largest \(=3\), smallest \(=-1\).
  • An endpoint can beat every interior candidate.
\[ \textbf{Closed Interval Method.} \text{ (1) Find all critical numbers of } f \text{ in } (a,b). \text{ (2) Evaluate } f \text{ at each critical number and at the endpoints } a,b. \text{ (3) The largest value is the absolute maximum; the smallest is the absolute minimum. } \]
Example 2

Find the absolute extrema of \(f(x)=x^{3}-3x+1\) on \([0,2]\).

Show answerHide answer
  1. Critical numbers: \(f'(x)=3x^{2}-3=3(x-1)(x+1)=0\), so \(x=\pm1\). Only \(x=1\) lies in \((0,2)\).
  2. Evaluate at candidates: \(f(0)=1\), \(f(1)=1-3+1=-1\), \(f(2)=8-6+1=3\).
  3. The maximum is \(f(2)=3\), the minimum is \(f(1)=-1\).
Answer: absolute maximum \(3\) at \(x=2\); absolute minimum \(-1\) at \(x=1\).

5. Data-science background — fitting a line by least squares

Optional background. Suppose a sensor produces three normalised input–output observations. We want one simple prediction rule that approximates all three observations.

Observation iInput \(x_i\)Observed output \(y_i\)
111

To keep the problem in one variable, choose a line through the origin, \(\hat y=wx\), and fit only its slope \(w\in\mathbb R\). The model predicts \(w,2w,3w\) at our three inputs. No such line passes through all three observations.

What least squares means

A residual is a prediction error: \(r_i(w)=\hat y_i-y_i=wx_i-y_i\). Least squares chooses the parameter that minimises the sum of the squared residuals. Squaring prevents positive and negative errors from cancelling.

\[S(w)=\sum_{i=1}^{3}(wx_i-y_i)^2.\] \[S(w)=(w-1)^2+(2w-2)^2+(3w-2)^2.\]

This is an absolute-minimum problem for the objective S, not a search for the smallest observed y-value. The data are fixed; changing w changes the predictions and therefore the errors.

Find the least-squares slope and its total squared error. Identify a stationary candidate, then prove it is the global minimum on \(\mathbb R\).

Show answerHide answer
  1. Expand the squared residuals: \[S(w)=14w^2-22w+9.\]
  2. Use the power and sum rules: \(S'(w)=28w-22\). Thus the only stationary candidate is \(w_*=11/14\).
  3. A candidate needs verification. Complete the square: \[S(w)=14\left(w-\frac{11}{14}\right)^2+\frac5{14}.\] Since the square is nonnegative for every real w, the unique global minimum is \(5/14\) at \(w=11/14\).
  4. The fitted predictions are \(11/14,11/7,33/14\). Subtracting the observed outputs gives residuals \(-3/14,-3/7,5/14\). Their squared sum is \((9+36+25)/196=5/14\).
Best fitted line: \(\hat y=(11/14)x\). Minimum squared error: \(S(w_*)=5/14\approx0.3571\).

Why not just choose w = 1? It fits the first two observations exactly, but misses the third by 1, giving \(S(1)=1\). Least squares allows smaller errors at several points to obtain a smaller total squared error.

This is one-parameter least-squares fitting. A general line \(\hat y=wx+b\) fits both a slope and an intercept; that is a two-variable optimization problem. Here the one-variable example lets us use this section’s stationary-point and global-minimum reasoning directly.

6. The Mean Value Theorem: the bridge from \(f'\) to \(f\)

\[ \textbf{Mean Value Theorem (MVT).} \text{ If } f \text{ is continuous on } [a,b] \text{ and differentiable on } (a,b), \text{ then there exists } c \in (a,b) \text{ such that } f'(c)=\frac{f(b)-f(a)}{b-a}. \]

Read it in 3 seconds

  • Blue line = average slope over the whole interval.
  • Green line = the derivative at one interior point.
  • Parallel means (f ′(c)) equals that average.
  • Rolle’s theorem is the case (f(a)=f(b)).

Although Stewart places the MVT in §4.3, it belongs conceptually with this section:

it is the theorem that turns "the derivative is positive" into "the function is increasing", and it is the reason antiderivatives are unique up to a constant.

Proof sketch via Rolle's theorem

Rolle's theorem: if \(f\) is continuous on \([a,b]\), differentiable on \((a,b)\), and \(f(a)=f(b)\), then \(f'(c)=0\) for some \(c\in(a,b)\). Proof: by the EVT, \(f\) attains its extrema on \([a,b]\); if an extremum is interior, Fermat's theorem gives \(f'=0\) there; if both extrema are at the endpoints, then \(f\) is constant and \(f'=0\) everywhere.

To prove the MVT, define \(g(x)=f(x)-\dfrac{f(b)-f(a)}{b-a}(x-a)\). Then \(g(a)=f(a)=g(b)\), so Rolle gives \(g'(c)=0\), i.e. \(f'(c)=\dfrac{f(b)-f(a)}{b-a}\).

Two consequences used constantly in later sections:

  • If \(f'(x)>0\) on an interval, then \(f\) is increasing there; if \(f'(x)<0\), \(f\) is decreasing. (This is the Increasing/Decreasing Test of §4.3.)
  • If \(f'(x)=0\) on an interval, then \(f\) is constant there; hence if \(F'=G'\), then \(F-G\) is constant. This is the "\(+C\)" of antiderivatives in §4.8.

7. Common mistakes

Assuming \(f'(c)=0\) means an extremum

Fermat's theorem is one-way. Check the sign of the derivative around \(c\), or the second derivative, before concluding. \(x^{3}\) at \(0\) is the standard counterexample.

Forgetting points where \(f'\) does not exist

Critical numbers include points where the derivative is undefined (corners, cusps, vertical tangents).

The absolute minimum of \(f(x)=|x|\) on \([-1,1]\) occurs at \(x=0\), where \(f'\) does not exist.

Ignoring endpoints

For a continuous function on a closed bounded interval, extrema can occur at endpoints.

The Closed Interval Method requires evaluating \(f\) at \(a\) and \(b\) explicitly — a critical point is only a candidate.

Applying the EVT to open or unbounded domains

On \((a,b)\), \([a,\infty)\), or \(\mathbb{R}\), a continuous function need not attain extrema. Check the limiting behaviour at the boundaries before declaring an optimum.

Necessary is not sufficient

A zero derivative identifies a candidate. To prove optimality, compare values or use a sign test. The domain and endpoints remain part of the problem.
