MA1508 Calculus · Chapter 4 · Section 4.6

Optimization

How to find the best value of a quantity that depends on several linked variables — the classic word problems of calculus, re-told as data-science and business decisions: revenue, inventory, portfolio risk, cost, and physical design. The method is always the same: set up the objective, reduce it to one variable, then apply §4.2's closed-interval method or the first/second derivative tests.

ONE EXAMPLE, BEFORE ANY THEORY

A shopkeeper can buy stock in bulk: a larger order earns a cheaper unit price, but any unsold stock is money thrown away. There is a best order size, and it is neither "as many as possible" nor "as few as possible".

Every optimisation problem has that same shape: something to maximise or minimise, plus a rule linking the variables that stops you choosing each of them freely. Use the rule to remove all but one variable, and §4.2 already knows how to finish.

Below, the same method is applied to a farmer's fence, a tin can, a cinema's ticket price, a shop's newspaper order and a spread of investments.

1. Motivation: the method of optimization

An optimization problem is a sentence with two ingredients: a quantity to be maximized or minimized (the objectiveObjectiveThe quantity you are trying to maximize or minimize — the function you differentiate.\( \max_{x}\ Q(x) \)), and a constraintConstraintThe equation that links the variables, used to eliminate all but one of them.\( g(x,y)=0 \) linking the variables. The method is uniform:

\[ \textbf{Method.} \text{ (1) Name the variables. } \text{(2) Write the objective } Q \text{ in terms of the variables. } \text{(3) Use the constraint to eliminate all but one variable. } \text{(4) Find the critical numbers of } Q \text{ on the relevant interval. } \text{(5) Use the closed-interval method or the tests of §4.3 to select the optimum. } \]

Three of the five Stewart modeling examples survive in this section in data-science clothing — the Hubble expansion (§4.2's example), the logistic population model, and the DVD-burner cost problem — and the business examples (revenue, inventory) are exactly the ones a data scientist will be asked to formalize for a product team.

Why the method matters beyond word problems: every hyperparameterHyperparameterA setting you choose before fitting (penalty strength, step size) rather than learn from data.\( \lambda,\ \eta \) choice, inventory policyInventory policyA rule for how much stock to order — an optimization problem under uncertainty.\( Q^{*}=\mu+\sigma\Phi^{-1}\!\left(\tfrac{C_{u}}{C_{u}+C_{o}}\right) \), and portfolio weightPortfolio weightThe fraction of your money placed in each asset.\( \textstyle\sum_{i}w_{i}=1 \) is an optimization problem. Calculus gives the exact answer when the objective is smooth and the constraint is simple; when it is not, this section still tells you what to compute numerically.

2. Worked example A: the fence — a pure geometry optimum

Example A

A farmer has 2400 ft of fencing and wants to fence off a rectangular field that borders a straight river; no fence is needed along the river. What dimensions maximize the enclosed area?

Show answerHide answer
  1. Set up. Let \(x\) be the length of each of the two equal sides perpendicular to the river, and \(y\) the length of the side parallel to the river. The constraint is \(2x+y=2400\), so \(y=2400-2x\).
  2. Objective. \[ A(x) \;=\; x\cdot y \;=\; x(2400-2x) \;=\; 2400x-2x^{2}, \qquad 0\le x\le1200. \] The domain: \(x\ge0\) and \(y=2400-2x\ge0\), so \(0\le x\le1200\).
  3. Critical point. \[ A'(x) \;=\; 2400-4x \;=\; 0 \quad\Rightarrow\quad x=600. \] Rules: power rule, constant-multiple, sum rule.
  4. Verify it is the maximum. \(A''(x)=-4<0\) everywhere, so \(A\) is concave down and \(x=600\) is the global maximum on the closed interval (the endpoints give \(A=0\)).
  5. Dimensions and value. \(y=2400-2(600)=1200\), so the field is \(600\) ft deep by \(1200\) ft along the river, and \[ A_{\max}=600\cdot1200=720{,}000\text{ ft}^{2}. \]
Answer: \(x=600\) ft (each of the two equal sides), \(y=1200\) ft (side parallel to the river), area \(720{,}000\) ft².

3. Worked example B: the can — minimizing surface area for a fixed volume

Example B

A cylindrical can must hold \(V=1000\) cm³. Find the radius \(r\) and height \(h\) that minimize the surface area (the amount of metal).

Show answerHide answer
  1. Constraint. Volume \(V=\pi r^{2}h=1000\), so \(h=1000/(\pi r^{2})\).
  2. Objective. Surface area = two lids + side: \[ S(r) \;=\; 2\pi r^{2} + 2\pi r h \;=\; 2\pi r^{2} + \frac{2V}{r} \;=\; 2\pi r^{2} + \frac{2000}{r}, \qquad r>0. \]
  3. Critical point. \[ S'(r) \;=\; 4\pi r - \frac{2000}{r^{2}} \;=\; 0 \quad\Rightarrow\quad r^{3}=\frac{2000}{4\pi}=\frac{500}{\pi} \quad\Rightarrow\quad r=\Bigl(\frac{V}{2\pi}\Bigr)^{1/3}=5.4192607014\text{ cm}. \]
  4. Height. \[ h \;=\; \frac{V}{\pi r^{2}} \;=\; 2r \;=\; 10.8385214028\text{ cm}. \] So the optimal can is as tall as it is wide (\(h=2r\)).
  5. Verify minimum. \(S''(r)=4\pi+4000/r^{3}>0\) for all \(r>0\), so \(S\) is convex and the critical point is the global minimum.
  6. Value. \[ S_{\min} \;=\; 2\pi r^{2}+\frac{2000}{r} \;=\; 553.5810445932\text{ cm}^{2}. \]
Answer: \(r=5.4192607014\) cm, \(h=10.8385214028\) cm, \(S_{\min}=553.5810445932\) cm².

4. Worked example C: the box — a three-variable problem reduced to one

Example C

A rectangular box with a square base and a top is to be made from \(10\) m² of material. Find the dimensions that maximize the volume.

Show answerHide answer
  1. Set up. Let \(x\) be the side of the square base and \(h\) the height. Surface area (top + bottom + four sides): \(2x^{2}+4xh=10\).
  2. Objective. \(V=x^{2}h\). From the constraint, \(h=(10-2x^{2})/(4x)\), so \[ V(x) \;=\; x^{2}\cdot\frac{10-2x^{2}}{4x} \;=\; \frac{10x-2x^{3}}{4} \;=\; \frac{5x-x^{3}}{2}, \qquad 0\le x\le\sqrt{5}. \]
  3. Critical point. \[ V'(x) \;=\; \frac{5-3x^{2}}{2} \;=\; 0 \quad\Rightarrow\quad x^{2}=\frac{5}{3} \quad\Rightarrow\quad x=\sqrt{\frac{5}{3}}=1.2909944487\text{ m}. \]
  4. Height. \[ h \;=\; \frac{10-2x^{2}}{4x} \;=\; \frac{10-10/3}{4\sqrt{5/3}} \;=\; \frac{20/3}{4\sqrt{5/3}} \;=\; \sqrt{\frac{5}{3}} \;=\; 1.2909944487\text{ m}. \] So the optimal box is a cube: \(x=h=\sqrt{5/3}\).
  5. Verify maximum. \(V''(x)=-3x<0\) on \((0,\sqrt{5})\), so \(V\) is concave down and the critical point is the global maximum.
  6. Value. \[ V_{\max} \;=\; x^{3} \;=\; \Bigl(\frac{5}{3}\Bigr)^{3/2} \;=\; 2.1516574146\text{ m}^{3}. \]
Answer: \(x=h=\sqrt{5/3}=1.2909944487\) m, maximum volume \(V_{\max}=2.1516574146\) m³.

5. Worked example D: revenue, rent, and price elasticity

Example D

A real-estate office manages \(100\) apartments. Each apartment rents for $800/month when all units are occupied; for each $10 increase in rent, one unit becomes vacant. What rent maximizes monthly revenue, and what is the revenue?

Show answerHide answer
  1. Set up. Let \(k\) be the number of $10 increases. Rent is \(800+10k\), occupied units are \(100-k\), so \[ R(k)=(800+10k)(100-k), \qquad 0\le k\le100. \]
  2. Expand and differentiate. \[ R(k)=80000+200k-10k^{2}, \qquad R'(k)=200-20k. \]
  3. Critical point. \(R'(k)=0\Rightarrow k=10\). \(R''(k)=-20<0\), so it is a maximum.
  4. Optimal rent and revenue. Rent \(=800+100=900\); occupied \(=90\); revenue \(=900\cdot90=\$81{,}000\).
Answer: rent $900/month, 90 units occupied, revenue $81,000.

Price elasticity: the sign of \(R'\) is the pricing rule

For a linear demand \(q=100-2p\), revenue is \(R(p)=p(100-2p)=100p-2p^{2}\), so \(R'(p)=100-4p\). The price elasticityPrice elasticity of demandThe percent change in demand per percent change in price. Negative for ordinary goods.\( E(p)=\dfrac{p}{q}\dfrac{dq}{dp} \) of demand is

\[ E(p) \;=\; \frac{p}{q}\frac{dq}{dp} \;=\; \frac{p}{100-2p}(-2) \;=\; -\frac{2p}{100-2p}. \]

The revenue derivative relates to elasticity: \(R'=q(1+E)\). Since \(q>0\), the sign of \(R'\) is the sign of \(1+E\): demand is inelasticInelasticDemand barely moves when the price changes, so a price rise brings in more revenue.\( |E|<1\Rightarrow R'>0 \) when \(|E|<1\), and elasticElasticDemand is price-sensitive, so a price cut brings in more revenue.\( |E|>1\Rightarrow R'<0 \) when \(|E|>1\).

Example E

Compute \(E\) and \(R\) at \(p=20,25,30\), and state the pricing rule.

Show answerHide answer
  1. \(p=20\): \(E=-2\cdot20/(100-40)=-40/60=-0.6667\), \(|E|<1\), \(R=20\cdot60=1200\).
  2. \(p=25\): \(E=-2\cdot25/(100-50)=-50/50=-1.0000\), \(|E|=1\), \(R=25\cdot50=1250\).
  3. \(p=30\): \(E=-2\cdot30/(100-60)=-60/40=-1.5000\), \(|E|>1\), \(R=30\cdot40=1200\).
  4. Revenue is maximized where \(E=-1\), i.e. \(R'=0\): \(p^{*}=25\), \(R_{\max}=1250\).
  5. Pricing rule. If \(|E|<1\) (inelastic), raising the price increases revenue (\(R'>0\)). If \(|E|>1\) (elastic), lowering the price increases revenue (\(R'<0\)). The sign of \(R'\) encodes the rule.
Answer: \(E(20)=-0.6667\), \(E(25)=-1\), \(E(30)=-1.5\); revenue maximized at \(p^{*}=25\) with \(R=1250\).

6. Worked example F: the newsvendor critical fractile

The newsvendorNewsvendor problemOrder once, before you know demand: too little loses sales, too much leaves leftovers.\( F(Q^{*})=\dfrac{C_{u}}{C_{u}+C_{o}} \) problem is the canonical inventory decision under uncertainty. You buy \(Q\) units at cost \(c\), sell at price \(p\), and salvage unsold units at \(s

\[ F(Q^{*}) \;=\; \frac{C_{u}}{C_{u}+C_{o}}, \qquad C_{u}=p-c \text{ (underage cost), } \quad C_{o}=c-s \text{ (overage cost)}. \]
Example F

With \(p=10\), \(c=4\), \(s=2\), and demand \(D\sim N(100,20^{2})\), find \(Q^{*}\) and the expected profit.

Show answerHide answer
  1. Costs. \(C_{u}=10-4=6\), \(C_{o}=4-2=2\), so \(F(Q^{*})=6/(6+2)=6/8=0.75\).
  2. Critical fractile. \(Q^{*}=\mu+\sigma\Phi^{-1}(0.75)=100+20\cdot0.6744897502=113.489795\).
  3. Expected profit. The newsvendor expected profit formula gives \(549.155748\) (marginal analysis verifies: ordering one more unit increases expected profit by \(C_{u}(1-F(Q))-C_{o}F(Q)\), which is zero at \(Q^{*}\)).
Answer: order \(Q^{*}=113.489795\) units; expected profit \(\approx549.16\).

The critical fractile is a first-order conditionFirst-order conditionThe equation "derivative equals zero" — the necessary condition for an interior optimum.\( f'(x^{*})=0 \) in disguise: the derivative of expected profit with respect to \(Q\) is \(C_{u}(1-F(Q))-C_{o}F(Q)\), and setting it to zero gives exactly the fractile formula. The same reasoning — marginal benefitMarginal benefitThe gain from one more unit of the decision variable.\( \Delta\Pi/\Delta Q \) equals marginal costMarginal costThe loss from one more unit; the optimum sits where the two balance.\( \Delta\text{cost}/\Delta Q \) — underlies every inventory and capacity decision.

7. Worked example G: minimum-variance portfolio weights

Example G

Two assets have returns with variances \(\sigma_{1}^{2}\), \(\sigma_{2}^{2}\) and correlationCorrelationHow much two quantities move together, on a scale from −1 to 1.\( \rho=\dfrac{\mathrm{Cov}(X,Y)}{\sigma_{X}\sigma_{Y}} \) \(\rho\). A portfolio puts weight \(w\) on asset 1 and \(1-w\) on asset 2. Its variance is \(V(w)=w^{2}\sigma_{1}^{2}+(1-w)^{2}\sigma_{2}^{2}+2w(1-w)\rho\sigma_{1}\sigma_{2}\). Find the weight that minimizes \(V\).

Show answerHide answer
  1. First derivative. \[ V'(w)=2w\sigma_{1}^{2}-2(1-w)\sigma_{2}^{2}+2(1-2w)\rho\sigma_{1}\sigma_{2}. \]
  2. Set \(V'=0\). Collect terms in \(w\): \[ 2w\sigma_{1}^{2}-2\sigma_{2}^{2}+2w\sigma_{2}^{2}+2\rho\sigma_{1}\sigma_{2}-4w\rho\sigma_{1}\sigma_{2}=0 \] \[ 2w\bigl(\sigma_{1}^{2}+\sigma_{2}^{2}-2\rho\sigma_{1}\sigma_{2}\bigr)=2(\sigma_{2}^{2}-\rho\sigma_{1}\sigma_{2}) \] \[ w^{*}=\frac{\sigma_{2}^{2}-\rho\sigma_{1}\sigma_{2}}{\sigma_{1}^{2}+\sigma_{2}^{2}-2\rho\sigma_{1}\sigma_{2}}. \]
  3. Second derivative. \[ V''(w)=2\sigma_{1}^{2}+2\sigma_{2}^{2}-4\rho\sigma_{1}\sigma_{2}=2\bigl(\sigma_{1}^{2}+\sigma_{2}^{2}-2\rho\sigma_{1}\sigma_{2}\bigr)>0 \] whenever \(\rho<1\) (the denominator is positive by Cauchy–Schwarz), so \(V\) is convex and \(w^{*}\) is the global minimum.
  4. Numbers. \(\sigma_{1}=0.20,\sigma_{2}=0.30,\rho=0.3\): \[ w^{*}=\frac{0.09-0.3\cdot0.2\cdot0.3}{0.04+0.09-2\cdot0.3\cdot0.2\cdot0.3}=\frac{0.09-0.018}{0.13-0.036}=\frac{0.072}{0.094}=0.76595745. \] \[ V_{\min}=w^{*2}\sigma_{1}^{2}+(1-w^{*})^{2}\sigma_{2}^{2}+2w^{*}(1-w^{*})\rho\sigma_{1}\sigma_{2}=0.03485106. \]
Answer: \(w^{*}=0.76595745\), minimum variance \(V_{\min}=0.03485106\).

This is the one-dimensional ancestor of MarkowitzMarkowitz portfolio selectionChoosing weights that trade expected return against variance — the origin of modern portfolio theory.\( \min_{w} w^{\top}\Sigma w \) portfolio selection: the minimum-variance frontier is found by minimizing a quadratic with a positive-definite Hessian — exactly the multivariate version of the \(V''>0\) test from §4.3.

8. Common mistakes and recap

Forgetting the constraint

An optimization problem always couples the variables. If you differentiate an objective with two variables still present, you are optimizing the wrong thing. Eliminate a variable using the constraint before differentiating.

Ignoring the domain

The relevant interval matters: the closed-interval methodClosed-interval methodOn a closed bounded interval, compare the interior critical points with the endpoints — the extreme value theorem guarantees the winner is among them.\( \max_{[a,b]}f=\max\{f(a),f(b),f(c_{i})\} \) (evaluate endpoints and critical points) is needed when the domain is closed and bounded; the derivative tests handle open intervals. A critical point outside the domain is not a candidate.

Checking only the first derivative

A critical point can be a maximum, a minimum, or neither. Confirm with the second derivative test or the sign of the first derivative around the point, and check endpoints when the interval is closed.

Rounding intermediate values

In the can problem, rounding \(r\) before computing \(h\) changes the answer. Carry full precision in intermediate steps; round only the final displayed result.
