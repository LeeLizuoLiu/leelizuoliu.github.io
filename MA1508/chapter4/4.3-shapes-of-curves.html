Shapes of Curves

Where a function rises and falls, where it bends, and why "bending the right way" is what makes optimization work. The data-science punchline: convexity is the reason optimization algorithms converge, and the second derivative test is the one-dimensional case of the positive-definite Hessian test.

ONE EXAMPLE, BEFORE ANY THEORY

Two hillsides are both level at the point where you are standing. One is the bottom of a valley; the other is the shoulder of a mountain. Standing still on flat ground, the slope cannot tell you which one you are on.

The second derivative can. It measures how the slope itself is changing — the bend. A curve that bends upward holds water; a curve that bends downward holds a peak.

This is not decoration. "Bends upward" is exactly the condition that makes an optimisation routine walk reliably to the bottom, and it is what guarantees a fitted model has one best answer instead of many.

1. Motivation: shape is why optimization works

In §4.2, Fermat's theorem reduced the search for extrema to solving \(f'(x)=0\). But a zero derivative is only a candidate: it could be a maximum, a minimum, or neither. To decide, and more importantly to know whether a candidate is the global optimum, we need to know the shape of \(f\) — where it increases, decreases, bends up, bends down.

The shape of the objective is the entire reason gradient-based optimization behaves well or badly:

  • A convexConvexBends upward everywhere, like a bowl. A bowl has one bottom, so an algorithm cannot get stuck.\( f''(x)\ge 0 \) loss (bends upward everywhere) has a single global minimum: any critical pointCritical pointWhere the derivative is zero — a candidate for an extremum, not yet a verdict.\( f'(c)=0 \) is the global minimizer, and gradient descentGradient descentWalk downhill by repeatedly stepping against the derivative — the basic first-order optimizer.\( x_{n+1}=x_{n}-\eta f'(x_{n}) \) converges to it from any start.
  • A concaveConcaveBends downward everywhere, like a hill. A concave log-likelihood has exactly one peak.\( f''(x)\le 0 \) log-likelihoodLog-likelihoodThe log of how probable the data you actually saw is, as a function of the unknown parameter.\( \ell(\theta)=\ln L(\theta) \) has a single global maximum — the maximum-likelihood estimate is unique.
  • A non-convex objective can have many local minima; which one an optimizer finds depends on where it starts.

This section develops the vocabulary: increasing/decreasing, concavity, inflection points, and the first and second derivative tests. Stewart's §4.4 (graphing with calculators) is folded in as a tooling card at the end.

2. Increasing and decreasing: the first derivative test

The Mean Value Theorem of §4.2 turns the sign of the derivative into the direction of the function:

\[ \textbf{Increasing/decreasing test.} \text{ If } f'(x) > 0 \text{ on an interval, } f \text{ is increasing there; if } f'(x) < 0, \text{ } f \text{ is decreasing there.} \]

Consequently, at a critical number \(c\) where \(f'\) changes sign, there is a local extremum — and the direction of the change tells which kind:

\[ \textbf{First derivative test.} \text{ If } f' \text{ changes from } + \text{ to } - \text{ at } c, \text{ then } c \text{ is a local maximum. If } f' \text{ changes from } - \text{ to } +, \text{ then } c \text{ is a local minimum.} \]

If \(f'\) does not change sign, \(c\) is neither — as with \(f(x)=x^{3}\) at \(x=0\).

Why the sign test is valid

This is the MVT consequence of §4.2, Card 6: for \(x_{1}0\), the MVT gives \(f(x_{2})-f(x_{1})=f'(c)(x_{2}-x_{1})>0\), so \(f(x_{2})>f(x_{1})\). The first derivative test then follows directly from the definition of a local maximum/minimum.

How to apply it. Find the critical numbers; they split the real line into intervals; evaluate \(f'\) at one point in each interval; read off the sign. This sign chartSign chartA table of the sign of the derivative on each interval — turns the roots into the directions of the curve.\( f'>0\Rightarrow\nearrow \) is the workhorse of the section.

3. Concavity and the second derivative test

A function is concave up where its graph bends upward (like \(x^{2}\)) and concave down where it bends downward (like \(-x^{2}\)). The precise definition is about the graph lying above or below its tangent lines; the calculus test is about the second derivative:

\[ \textbf{Concavity test.} \text{ If } f''(x) > 0 \text{ on an interval, } f \text{ is concave up there; if } f''(x) < 0, \text{ } f \text{ is concave down.} \]

A point where the concavity changes — where \(f''\) changes sign — is an inflection pointInflection pointWhere the bend flips from upward to downward (or back) — a sign change of the second derivative, not an extremum.\( f''(c)=0\ \text{and changes sign} \) (provided \(f\) is continuous there).

\[ \textbf{Second derivative test.} \text{ If } f'(c)=0 \text{ and } f''(c) > 0, \text{ then } c \text{ is a local minimum; if } f'(c)=0 \text{ and } f''(c) < 0, \text{ then } c \text{ is a local maximum. If } f''(c)=0, \text{ the test is inconclusive.} \]
Proof sketch: the second derivative test

Assume \(f'(c)=0\) and \(f''(c)>0\). By the linear approximation of §3.8, for \(x\) near \(c\),

\[ f(x) \;=\; f(c) + f'(c)(x-c) + \tfrac12 f''(c)(x-c)^{2} + o\bigl((x-c)^{2}\bigr) \;=\; f(c) + \tfrac12 f''(c)(x-c)^{2} + o\bigl((x-c)^{2}\bigr). \]

Since \(f''(c)>0\), the quadratic term is positive on both sides of \(c\), so \(f(x)\ge f(c)\) for \(x\) close to \(c\): a local minimum. The \(f''(c)<0\) case is the mirror image.

Gap named: the \(o((x-c)^{2})\) remainder term is quoted from Taylor's theorem, which is proved later in the course; the geometric argument via tangent lines is the complete proof at this stage.

The multivariate translation: for a smooth function of many variables, "\(f''(c)>0\)" becomes "the HessianHessian matrixThe many-variable version of the second derivative: a matrix of second partial derivatives. Positive definite means a bowl.\( H_{ij}=\dfrac{\partial^{2}f}{\partial x_{i}\partial x_{j}} \) matrix at the critical point is positive definite", and the second derivative test becomes the Hessian test. One-dimensional concavity is the exact prototype.

4. Worked example A: a complete shape analysis of a cubic

Example A

Analyze \(f(x)=x^{3}-3x^{2}-9x+8\): find the intervals where it increases and decreases, its local extrema, the concavity, and the inflection point.

Show answerHide answer
  1. First derivative. \[ f'(x) = 3x^{2} - 6x - 9 = 3(x^{2}-2x-3) = 3(x-3)(x+1). \] Rules: power rule, constant-multiple, sum rule; then factor the quadratic. Critical numbers: \(x=-1\) and \(x=3\).
  2. Sign chart for \(f'\). The sign of \(3(x-3)(x+1)\):
    • \(x<-1\): both factors negative, product positive, \(f'>0\), \(f\) increasing.
    • \(-10\), \(x-3<0\), product negative, \(f'<0\), \(f\) decreasing.
    • \(x>3\): both positive, \(f'>0\), \(f\) increasing.
  3. First derivative test. At \(x=-1\), \(f'\) changes \(+\) to \(-\), so a local maximum with \(f(-1)=(-1)^{3}-3(-1)^{2}-9(-1)+8=-1-3+9+8=13\). At \(x=3\), \(f'\) changes \(-\) to \(+\), so a local minimum with \(f(3)=27-27-27+8=-19\).
  4. Second derivative. \[ f''(x) = 6x - 6 = 6(x-1). \] Rules: power rule on \(3x^{2}\), constant-multiple on \(-6x\), constant rule on \(-9\).
  5. Concavity. For \(x<1\), \(f''<0\): concave down. For \(x>1\), \(f''>0\): concave up. The concavity changes at \(x=1\), where \(f(1)=1-3-9+8=-3\), so \((1,-3)\) is the inflection point.
  6. Second derivative test cross-check. At \(x=-1\), \(f''(-1)=6(-2)=-12<0\), confirming a local maximum. At \(x=3\), \(f''(3)=6(2)=12>0\), confirming a local minimum. Consistent with the sign chart.
Answer: increasing on \((-\infty,-1)\cup(3,\infty)\), decreasing on \((-1,3)\); local maximum \(f(-1)=13\), local minimum \(f(3)=-19\); concave down on \((-\infty,1)\), concave up on \((1,\infty)\); inflection point \((1,-3)\).

The two tests agree, and each contributes something the other does not: the sign chart gives the global direction, the second derivative test checks a candidate locally. In higher dimensions the Hessian test is the only one of the two that generalizes directly.

5. Worked examples B and C: log-likelihood concavity and the test-error curve

Example B: the logistic log-likelihood is strictly concave

Example B

For the logistic model \(p(x)=\sigma(wx)\) with data \(X=[-2,-1,0,1,2,3]\), \(Y=[0,1,1,0,1,1]\), the second derivative of the log-likelihood is

\[ \ell''(w) \;=\; -\sum_{i=1}^{6} p_{i}\bigl(1-p_{i}\bigr) x_{i}^{2}, \qquad p_{i}=\sigma(wx_{i}). \]

Show that \(\ell''(w)<0\) for every \(w\), and locate the maximum-likelihood estimate.

Show answerHide answer
  1. Why each term is negative. \(\sigma(wx_{i})\in(0,1)\), so \(p_{i}(1-p_{i})>0\), and \(x_{i}^{2}\ge0\) with at least one \(x_{i}\neq0\). Hence every term is \(\le0\) and at least one is strictly negative: \(\ell''(w)<0\) for all \(w\). The log-likelihood is strictly concave.
  2. Evaluate at sample points. Using \(p_{i}=\sigma(wx_{i})\): \[ w=-3:\ \ell''=-0.11120; \qquad w=-1:\ \ell''=-1.63976; \qquad w=0:\ \ell''=-4.75000; \] \[ w=1:\ \ell''=-1.63976; \qquad w=3:\ \ell''=-0.11120; \qquad w=5:\ \ell''=-0.01366. \] All negative, matching the theory; the magnitude is largest near \(w=0\), where the probabilities are closest to \(1/2\).
  3. Consequence. Strict concavity means the critical point of \(\ell\) — the solution of the score equation \(\ell'(w)=0\) — is the unique global maximum. Newton's method from \(w_{0}=0\) reaches \(w\approx0.6204890\) in four steps (worked in §4.7): the MLE.
Answer: \(\ell''(w)<0\) everywhere, so \(\ell\) has a unique global maximum at \(w^{*}\approx0.6204890\).

Example C: the test-error curve has an interior minimum

Example C

A regularized model is trained along a path of penalty strengths \(\lambda\). The training error decreases monotonically as the model becomes more flexible, while the test error is U-shaped. Suppose the test-error curve has its minimum at \(\lambda^{*}=2.8796\) with test error \(0.40867\). Interpret the shapes.

Show answerHide answer
  1. Training error: decreasing for all \(\lambda\), so its derivative is always negative. More flexibility always fits the training data better.
  2. Test error: at the optimum, \(E'_{\text{test}}(\lambda^{*})=0\) by Fermat's theorem; the second derivative test gives \(E''_{\text{test}}(\lambda^{*})>0\), a local — and on a convex U-shape, global — minimum.
  3. Interpretation. Left of \(\lambda^{*}\), increasing \(\lambda\) (more regularization) reduces test error: the model is overfitting. Right of \(\lambda^{*}\), more regularization hurts: the model is underfitting. The minimum separates the two regimes, and its location is found by the same calculus as every other optimization.
Answer: training error is monotone decreasing (overfitting on the left, underfitting on the right); test error has its minimum at \(\lambda^{*}=2.8796\) with value \(0.40867\).

Examples B and C are the two canonical shapes of machine learning: the concave log-likelihood with a unique maximum, and the convex generalization-error curve with a unique minimum. Recognizing which shape a curve has tells you whether a critical point is the answer or just a candidate.

6. Worked examples D and E: the sigmoid and the entropy

Example D: the sigmoid — always increasing, one inflection point

Example D

For the sigmoidSigmoidThe S-shaped curve that squashes any real number into a probability between 0 and 1.\( \sigma(z)=\dfrac{1}{1+e^{-z}} \) \(\sigma(x)=\dfrac{1}{1+e^{-x}}\), compute \(\sigma'\), \(\sigma''\), and use them to describe the shape: intervals of increase, concavity, inflection point.

Show answerHide answer
  1. First derivative. Writing \(\sigma=(1+e^{-x})^{-1}\) and applying the chain rule: \[ \sigma'(x) \;=\; -(1+e^{-x})^{-2}\cdot(-e^{-x}) \;=\; \frac{e^{-x}}{(1+e^{-x})^{2}} \;=\; \sigma(x)\bigl(1-\sigma(x)\bigr). \] The last equality is the standard identity, checked by expanding \(\sigma(1-\sigma)\).
  2. Sign of \(\sigma'\). Since \(0<\sigma(x)<1\), \(\sigma'(x)>0\) for all \(x\): the sigmoid is increasing everywhere, from asymptote \(y=0\) as \(x\to-\infty\) to \(y=1\) as \(x\to+\infty\). At \(x=0\): \(\sigma(0)=0.5\) and \(\sigma'(0)=0.5\cdot0.5=0.25\).
  3. Second derivative. Differentiate \(\sigma'=\sigma(1-\sigma)\) by the product rule and the chain rule: \[ \sigma''(x) \;=\; \sigma'(1-\sigma) - \sigma\sigma' \;=\; \sigma(1-\sigma)\bigl[(1-\sigma)-\sigma\bigr] \;=\; \sigma(x)\bigl(1-\sigma(x)\bigr)\bigl(1-2\sigma(x)\bigr). \]
  4. Sign of \(\sigma''\). The factor \(\sigma(1-\sigma)>0\), so the sign is that of \(1-2\sigma(x)\): positive when \(\sigma(x)<1/2\) (i.e. \(x<0\)), negative when \(\sigma(x)>1/2\) (i.e. \(x>0\)). Hence concave up on \((-\infty,0)\), concave down on \((0,\infty)\), with an inflection point at \(x=0\).
Answer: \(\sigma'=\sigma(1-\sigma)>0\) everywhere; \(\sigma''=\sigma(1-\sigma)(1-2\sigma)\) changes sign at \(x=0\), so \((0,0.5)\) is the inflection point.

  1. First derivative. Using the product rule and \((\ln p)'=1/p\): \[ H'(p) \;=\; -\ln p - 1 + \ln(1-p) + 1 \;=\; -\ln p + \ln(1-p) \;=\; \ln\frac{1-p}{p}. \] Check the term \(-(1-p)\ln(1-p)\): derivative is \(-[-\ln(1-p)+(1-p)\cdot\frac{-1}{1-p}]=-(-\ln(1-p)-1)=\ln(1-p)+1\). 7. Tooling: graphing to locate, derivatives to confirm (Stewart §4.4)

Stewart's §4.4, Graphing with Calculators and Computers, is folded into this section as a tooling card, because its message is a workflow rather than a new rule:

\[ \textbf{Workflow.} \text{ (1) Plot to find the candidate regions. } \quad \text{(2) Use } f' \text{ to confirm monotonicity and extrema. } \quad \text{(3) Use } f'' \text{ to confirm concavity and inflection points. } \]
  • A plot locates, calculus confirms. Graphs are the fastest way to see that a function has, say, two critical points in \([-10,10]\); the derivative then verifies they are genuine and decides maximum versus minimum, which a plot can only suggest at pixel resolution.
  • Choose the window deliberately. The default window may hide an inflection point or an asymptote; rescale until every feature of interest is visible, then check the boundaries for behaviour at infinity.
  • Beware misleading plots. A function that looks flat may still be increasing (e.g. \(\ln x\) near large \(x\)); a steep plot may hide a local extremum between pixels. The derivative is the arbiter.

In data science, the analogue is exploratory plotting before fitting: plot the loss surfaceLoss surfaceThe plot of the objective against the parameters — optimization is walking on this surface.\( \text{minimize } L(\theta) \) or the validation curveValidation curveError measured on held-out data as a tuning knob is varied; U-shaped when overfitting and underfitting trade off.\( E_{\text{val}}(\lambda) \) first, then let derivatives (or their numerical proxies, gradients) confirm what the plot suggests. The calculus workflow of this card is the same two-step discipline.

8. Common mistakes and recap

Sign of \(f'\), not of \(f\)

The sign of \(f'\) tells whether \(f\) is increasing — it says nothing about the sign of \(f\) itself. \(f(x)=x^{2}\) is decreasing on \((-\infty,0)\) even though \(f>0\) there.

Inflection points are about concavity, not extrema

At an inflection point \(f''=0\) (or is undefined), but \(f'\) need not be zero. In the cubic example, \(x=1\) is an inflection point while the extrema are at \(x=-1,3\). An inflection point is where the slope stops increasing and starts decreasing.

\(f''(c)=0\) is inconclusive

The second derivative test says nothing when \(f''(c)=0\): \(x^{4}\) has a local minimum at \(0\) with \(f''(0)=0\), while \(-x^{4}\) has a local maximum there. Return to the sign chart in such cases.

Concavity is a global property, not a point property

Calling a function "convex" means its second derivative is nonnegative on the whole interval — checking one point is not enough. Strict concavity of the log-likelihood (Example B) is a global statement, which is exactly what makes the MLE unique.

The section in one line: \(f'\) tells you where the function goes, \(f''\) tells you how it bends, and a loss that bends the right way everywhere is a problem your optimizer can actually solve.
